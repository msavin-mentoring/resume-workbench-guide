# Кандидаты

Этот каталог содержит прежние локальные черновики. Для новых учеников используйте отдельные локальные и приватные GitHub-репозитории по [WORKFLOW.md](../WORKFLOW.md); новые пакеты здесь не создаются. Личные PDF, сырой student-context и записи разговоров храните отдельно в защищённом источнике и ссылайтесь на них из ledger.

Рабочий порядок: project dossier и claim ledger → vacancy coverage → резюме → interview legend → проверка вместе с учеником. Если пользователь просит только аудит, не менять публичное резюме до согласования формулировок.
