# Кандидаты

На каждого ученика создать отдельный каталог с копиями четырёх файлов из `../templates/`. Назвать каталог нейтральным slug, например `candidate-01`; личные PDF, сырой student-context и записи разговоров хранить отдельно в защищённом источнике и ссылаться на них из ledger.

Рабочий порядок: project dossier и claim ledger → vacancy coverage → резюме → interview legend → проверка вместе с учеником. Если пользователь просит только аудит, не менять публичное резюме до согласования формулировок.
