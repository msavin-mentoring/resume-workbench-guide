# Первичная карта требований

Это навигация по [исходному списку](vacancy-requirements-raw.md), **не** статистика по отдельным вакансиям. Формулировки ниже встречаются в сыром тексте, но их частота и актуальность для конкретного ученика требуют отдельного набора вакансий.

| Тема | Примеры спроса в списке | Что искать в собственном опыте ученика |
|---|---|---|
| PHP/backend | PHP 8+, ООП, SOLID, проектирование серверных приложений | Реальные версии, роль, сложные модули, граница backend-ответственности |
| Фреймворк | Symfony, Laravel, Doctrine, Messenger | Подтверждённый фреймворк; переносимые практики отдельно от Symfony-only компонентов |
| API и интеграции | REST API, платежи, внешние системы, иногда GraphQL/gRPC | Контракты, ошибки, идемпотентность, timeout/retry, результат интеграции |
| Данные | PostgreSQL/MySQL, сложный SQL, индексы, транзакции, оптимизация | Схемы, запросы, EXPLAIN, размер локальной задачи и замер до/после |
| Асинхронность и кэш | RabbitMQ, Kafka, Redis, фоновые задачи | Очереди и причины их применения; retry, DLQ/inbox/outbox только при подтверждении |
| Архитектура и надёжность | Модули/микросервисы, отказоустойчивость, highload, legacy | Конкретная подсистема, ограничение, граница личного вклада и наблюдаемый эффект |
| Качество и поставка | Unit/integration tests, code review, Git, Docker, CI/CD | Тестируемые сценарии, review-практика, pipeline, релизы; обычное — в типовые задачи |
| Наблюдаемость | Логи, мониторинг, Prometheus/Grafana, ELK/Sentry | Что измеряли, как обнаруживали сбои, как это повлияло на диагностику |

Сначала выбирать релевантные темы по целевой роли и настоящим проектам, затем проверять факты. Не превращать эту таблицу в список навыков кандидата.
